# Ising analysis of Purkinje-cell populations: experiment tracker

This repo fits pairwise maximum-entropy (Ising) models to Neuropixels recordings of mouse cerebellar
Purkinje cells during reaching. The data is the Calame, Becker & Person dataset: 21 sessions, 6 mice,
3 blocks each (baseline, closed-loop stimulation, washout). The goal is one paper on what the Ising model
reveals that other methods cannot.

- **How to run or add an experiment:** [PROTOCOL.md](PROTOCOL.md). Start one with `bash tools/new_experiment.sh`.
- **Paper-facing results (single source of truth):** [RESULTS_LOG_FOR_PAPER.md](RESULTS_LOG_FOR_PAPER.md)
- **Full project handoff (data conventions, cluster gotchas):** [09_claude_science_handoff/HANDOFF_CLAUDE_CODE.md](09_claude_science_handoff/HANDOFF_CLAUDE_CODE.md)
- **Shared code:** [shared/](shared/README.md). The original MCH pipeline is in `old_code/energy_over_time_script/`.

## Layout

```
ising_EnergyOverTime/
├── README.md                  # this tracker
├── PROTOCOL.md                # how experiments are run and recorded
├── RESULTS_LOG_FOR_PAPER.md   # the single paper-facing results log
├── NN_<experiment>/           # one folder per experiment (see PROTOCOL.md)
├── _template/                 # copied by tools/new_experiment.sh
├── tools/                     # new_experiment.sh, log_run.sh, update_status.py
├── shared/                    # cross-experiment code (src/ package, aggregation scripts)
├── docs/                      # older project overview and session-report galleries
└── old_code/                  # everything from before the reorganization (original pipeline, notebooks, MATLAB)
```

Legacy folders (E01–E06) predate this protocol. Their `notes/` hold the original analysis notes, and
their per-session outputs live on the cluster under `results/` (gitignored).
