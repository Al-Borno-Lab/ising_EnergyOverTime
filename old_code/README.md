# ising_EnergyOverTime

Pairwise maximum-entropy (Ising) analysis of cerebellar Purkinje-cell populations during reaching (Al Borno lab).

**Start here: [energy_over_time_organized/README.md](energy_over_time_organized/README.md)**, the experiment tracker with the status of every experiment and the ongoing analysis.
Running or adding an experiment: [energy_over_time_organized/PROTOCOL.md](energy_over_time_organized/PROTOCOL.md).

Other top-level folders:
- `energy_over_time_script/`: the original MCH fitting pipeline (`main.py`, `model.py`, ...), used by the experiments.
- `Energy_Analysis/`, `CompileAbigails.m`, etc.: earlier MATLAB/Python work from `main`.
