# 09_claude_science_handoff

Work from the Claude Science sessions (through 2026-10-07): time-varying-field Ising model, exact maximum-likelihood
thermodynamics, H0 synthetic validation and the operating-point pre-registration. Start with `HANDOFF_CLAUDE_CODE.md`,
then `reports/COLLABORATION_BRIEF.md`, `reports/RESULTS_LOG_FOR_PAPER.md` and `reports/PREREGISTRATION_OPERATING_POINT.md`.

- `code/`: sandbox code (`thermo_model.py`, `tvfield_model.py`, `run_*.py`, ...). Files named `a__b__c.py` are copies of cluster file `a/b/c.py`.
- `reports/`: all markdown reports. `reports/RESULTS_LOG_FOR_PAPER.md` is the newest version of the results log.
- `tables/`, `figures/`: result tables and figures (committed with `git add -f`).
- `papers_and_pdfs/ISING_FINDINGS_FIGURES.pdf`: captioned findings figures. Third-party papers are not committed.
- `data/` (not in git, too large): on the cluster at this same path. `data/spikes_v2.npz` is the main local data file.
