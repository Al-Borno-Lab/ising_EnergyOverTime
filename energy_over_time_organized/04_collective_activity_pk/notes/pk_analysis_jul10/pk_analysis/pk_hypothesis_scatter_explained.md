# `pk_hypothesis_scatter.png` — axis and collective-region reference

Generated by `_plot_hypothesis_scatter()` in `pk_j_analysis.py`. Each point on
the plot is one session/stim pair. Point color/marker (red circle = "J peak",
blue triangle = "No J peak") is an independent classification — whether a
J-coupling peak was detected in the kinematic analysis window — and plays no
role in either axis or in the shaded region; it exists only to test the
hypothesis (stated in the figure's title) that J peaks preferentially occur
in the "collective" region.

## Background: what `P(K)` is

For each time bin, `K = Σᵢ σᵢ` is the number of neurons simultaneously
spiking (binarized population activity, `σ ∈ {0,1}^N`). Three distributions
over `K` are computed per session (see `plot_model_quality_summary_from_arrays`
in `visualization.py`):

- **`P_data(K)`** — empirical histogram: `(# bins with K spikes) / (total bins)`.
- **`P_independent(K)`** — the distribution predicted if neurons fired
  independently, using only each neuron's own empirical rate `p_i = ⟨σᵢ⟩`
  (a Poisson-binomial: the coefficient of `z^K` in `∏ᵢ [(1-p_i) + p_i z]`).
  Contains **zero** pairwise structure.
- **`P_ising(K)`** — histogram of `K` from Monte Carlo samples drawn from the
  fitted pairwise maximum-entropy (Ising) model, which includes per-neuron
  rates **and** all pairwise couplings `J_ij`.

Comparing these three curves reveals whether pairwise correlations actually
help explain the population's simultaneous-firing statistics, or whether an
independent-neuron model would predict the same thing.

## X-axis — `ising_indep_dist`

```python
ising_indep_dist = float(np.sum(np.abs(p_ising - p_indep)))
```

```
ising_indep_dist = Σ_K | P_ising(K) − P_independent(K) |
```

Total-variation distance between the Ising model's predicted `P(K)` and the
independent model's predicted `P(K)` — **not** compared to the data. It only
measures how differently the two *models* behave from each other:

- Small value → Ising and independent models make essentially the same
  prediction, so there is nothing to gain by looking at pairwise structure.
- Large value → the two models genuinely diverge, so asking which one wins
  (the y-axis, below) becomes a meaningful test of whether correlations matter.

## Y-axis — Ising fit advantage

```python
def _safe_r(a, b):
    if len(a) < 2 or np.std(a) < 1e-12 or np.std(b) < 1e-12:
        return np.nan
    return float(np.corrcoef(a, b)[0, 1])

r_ising       = _safe_r(p_data, p_ising)
r_independent = _safe_r(p_data, p_indep)
```

`r_ising` / `r_independent` are the Pearson correlation between each model's
predicted `P(K)` curve and the empirical `P_data(K)` curve — i.e. how well
that model's shape tracks the real distribution across all `K`. The plotted
y-value is the difference:

```
Ising fit advantage = r_ising − r_independent
```

Positive → Ising tracks the data curve more tightly than the independent
model. Negative → the independent model fits better.

## The two threshold constants

Defined once, module-level, in `pk_j_analysis.py` (and reused everywhere the
collective classification is computed, e.g. `_pk_metrics`, `_plot_session`,
`_plot_hypothesis_scatter`, `compare_sessions.py`), so the shaded region can
never drift out of sync with the rule that actually classifies sessions:

```python
R_TOL = 0.02
DIST_THRESHOLD = 0.10
```

| Constant | Value | Axis it applies to | What it means |
|---|---|---|---|
| `R_TOL` | `0.02` | y-axis (`r_ising − r_independent`) | Tolerance band on the fit-quality comparison. `r_ising`/`r_independent` are noisy correlation estimates, so requiring Ising to be *strictly* better than independent would reject sessions where the two are essentially tied. Ising is allowed to be up to `0.02` *worse* in raw correlation and still count as "at least as close" to the data. This is why the shaded region's lower edge sits at `y = −0.02`, not `y = 0`. |
| `DIST_THRESHOLD` | `0.10` | x-axis (`ising_indep_dist`) | Minimum-effect-size filter. If Ising and independent predict nearly identical `P(K)` curves (`ising_indep_dist` small), "Ising fits at least as well" is a vacuous statement — two near-identical curves obviously fit the data about equally well. Requiring `ising_indep_dist > 0.10` ensures the two models are meaningfully different before crediting Ising's fit quality as evidence of collective (pairwise-driven) structure. |

## Collective-region rule

```python
ising_closer = bool(
    (not np.isnan(r_ising)) and (not np.isnan(r_independent))
    and r_ising >= r_independent - R_TOL
)
is_collective = bool(ising_closer and ising_indep_dist > DIST_THRESHOLD)
```

A session is flagged **collective** exactly when both hold:

```
r_ising  ≥  r_independent − 0.02      (Ising fits at least as well, within tolerance)
   AND
ising_indep_dist  >  0.10             (the two models actually predict different P(K))
```

This is precisely the green-shaded rectangle in the figure:

```python
ax.axhspan(-R_TOL, max(ylim[1], 0.1),
           xmin=DIST_THRESHOLD / xlim_hi, xmax=1.0,
           color="lightgreen", alpha=0.25, zorder=0,
           label=f"Collective region (dist > {DIST_THRESHOLD:g}, "
                 f"advantage ≥ −{R_TOL:g})")
```

- Vertical dashed line at `x = 0.10` — the `DIST_THRESHOLD` cutoff.
- Horizontal dashed line at `y = −0.02` — the `R_TOL` cutoff.
- Shaded region — `x > 0.10 AND y ≥ −0.02`; points inside are classified
  "collective."

The hypothesis under test (per the figure's `suptitle`) is that sessions
with a detected J-coupling peak (red circles) preferentially fall inside
this region, while sessions without a J peak (blue triangles) fall outside it.

## Contingency test: J peak vs. collective region

Computed directly from `pk_j_summary.csv` (63 session/stim rows), using the
`has_j_peak` and `is_collective` columns already in that file (no
recomputation needed — `is_collective` there is exactly `ising_closer AND
ising_indep_dist > DIST_THRESHOLD`, the same rule as above):

```python
import pandas as pd
from scipy.stats import fisher_exact

df = pd.read_csv("pk_j_summary.csv")
peak, no_peak = df[df["has_j_peak"]], df[~df["has_j_peak"]]

n_peak, n_peak_collective     = len(peak), peak["is_collective"].sum()
n_nopeak, n_nopeak_collective = len(no_peak), no_peak["is_collective"].sum()

table = [[n_peak_collective, n_peak - n_peak_collective],
         [n_nopeak_collective, n_nopeak - n_nopeak_collective]]
odds, p = fisher_exact(table)
```

Result (N = 63 sessions total):

| | Collective | Not collective | Total |
|---|---|---|---|
| J peak | 37 | 2 | 39 |
| No J peak | 7 | 17 | 24 |

- J-peak sessions: **37 / 39 (94.9%)** fell in the collective region.
- No-peak sessions: **7 / 24 (29.2%)** fell in the collective region.
- Fisher's exact test: **p = 4.3 × 10⁻⁸**, odds ratio ≈ **44.9**.
